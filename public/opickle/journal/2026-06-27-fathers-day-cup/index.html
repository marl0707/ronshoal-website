Father's Day O.pickle THE HOOD

Father's Day Pickleball Match

6月27日、THE HOODに集まったO.pickleの仲間たち。父の日の夜、コートにはプレーを楽しむ声と、負けたくない気持ちが同じ温度で流れていた。

Date Saturday, June 27
Time 5:00 gather / 5:30 start
Community O.pickle
Venue THE HOOD Pickleball

Prologue

父の日の夜、コートが少しだけ特別になった。

Schedule 5:00 PM集合、5:30 PM試合開始、8:00 PM終了
Rule ダブルスのチームは当日くじ引きで決定
Entrants Masato / Masamichi / Gogo / Sejima~Ru / Hiroki / Kyon / Hiroyuki / Jun / Mori / Joji

Match Report

5時半、空気が試合へ切り替わる。

集合時間を過ぎると、青いコートの周りに参加者が集まり始めた。名前が呼ばれ、ラケットを手にする。いつもの会話の延長に、少しだけ勝負の気配が混ざっていく。

この日のよさは、和やかさの中に本気があることだった。笑いながらコートに入り、ボールが浮いた瞬間だけ表情が変わる。父の日らしいあたたかさと、ゲームへの集中が同じ場所にあった。

Rally

速さより、判断が勝負を分ける。

ネット際では、強打より一歩早い判断がものを言う。浮いたボールに詰める。角度を消す。相手の一歩先へ置く。短い距離で交わされる読み合いが、ピックルボールの面白さを引き出していた。

勝ちたいから、声が出る。楽しいから、最後まで笑っていられる。

Between Games

試合の合間に、もう一つの表情があった。

スコアを追う目、ボードの前で交わされる会話、名前を見つけて笑う声。コートの外にいる時間にも、この会らしい距離の近さが出ていた。

Video Moments

歓声まで残しておきたい夜だった。

Selected Frames

写真に残ったのは、勝敗の先にある表情。

メダルを手にした顔、家族と並ぶ姿、コートに立つ背中。どの写真にも、勝敗だけでは拾いきれない父の日の時間が写っている。

JUNE 27 MATCH

6月27日、THE HOODに集まったO.pickleの仲間たちと家族の時間。勝負は真剣に、余韻はあたたかく。父の日のコートには、また集まりたくなる理由が残っていた。
